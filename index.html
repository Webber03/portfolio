Infraestrutura VPS Linux & Google Drive API Vault

Arquitetura de servidores em produção configurada em Linux VPS com gerenciamento de processos via PM2 e proxy reverso Nginx com certificados SSL TLS 1.3 automáticos. Integração avançada com a API Google Drive v3 (OAuth2) para armazenamento seguro e sincronização de documentos jurídicos e bancários criptografados.

Cluster de Processos: PM2 com reinicialização resiliente e monitoramento de consumo de memória.
Armazenamento em Nuvem: Upload assíncrono em chunks com controle rigoroso de permissões e pastas isoladas por cliente.
Segurança e Rede: Nginx com headers HTTP de segurança (HSTS, CSP), rate limiting e portas de banco isoladas.

MULTI-TENANCY

Isolamento Físico de Banco

Cada cliente corporativo possui seu próprio banco de dados PostgreSQL com credenciais, portas e pools independentes. Vazamento entre inquilinos é fisicamente impossível no nível de conexão.

GOOGLE CLOUD

Cofre de Documentos v3

Integração via OAuth2 com a API do Google Drive v3 com renovação automática de tokens via refresh token. Upload assíncrono de contratos, relatórios e documentos com validação de formato e hash MD5.

MOTOR DE VENDAS

Pipeline Duplo SDR / Closer

Mecanismo que separa a qualificação prévia (SDR) do fechamento (Closer). Leads são despachados de forma equitativa por fila Round-Robin com monitoramento de tempo de resposta em tempo real.

LINUX SERVER

Resiliência Operacional PM2

Servidor Ubuntu Linux dedicado rodando processos gerenciados por cluster PM2 com reinicialização em falha, rotação de logs e proxy Nginx roteando tráfego por cabeçalhos de domínio.

Engenharia de Software Aplicada a Produtos de IA

Como estudante de Engenharia de Software e desenvolvedor atuando na prática, encaro ferramentas e modelos de IA como alavancas de ponta a ponta para resolver gargalos reais de negócio. Meu foco não é a pesquisa teórica de modelos, mas sim a engenharia aplicada: saber estruturar o que pedir, integrar APIs com contratos rígidos, validar saídas com JSON Schema e transformar inteligência artificial em produto funcional e produtivo para as empresas.

Padrões Técnicos Implementados

  • Extração Estruturada & Function Calling: Conversão de contratos, mensagens e documentos não estruturados em payloads JSON tipados e limpos, prontos para consumo por bancos e sistemas internos.
  • Injeção de Contexto & Regras de Negócio: Alimentação dinâmica de regras comerciais e parâmetros de validação para manter as inferências 100% alinhadas às diretrizes da empresa.
  • Tratamento Determinístico & Guardrails: Validação rigorosa de schemas e fallbacks automáticos antes de qualquer persistência, prevenindo inconsistências em bancos de dados corporativos.
  • Automação End-to-End: Conexão direta dos resultados a bancos relacionais (PostgreSQL), plataformas de CRM e esteiras operacionais diárias.

Impacto Prático no Negócio

Redução drástica do tempo gasto em triagem e conferência de documentos, eliminação de gargalos manuais e aumento expressivo na capacidade operacional da equipe sem perda de qualidade.

Atendimento CRM SaaS Whitelabel — Arquitetura

Stack: Node.js, PostgreSQL, Docker, Nginx • Ambiente: Produção Corporativa Privada

Conceito & Solução

O sistema foi projetado para resolver o problema clássico de CRMs monolíticos: acomodar múltiplos inquilinos corporativos com requisitos visuais, regras de negócio e bancos de dados totalmente separados sem precisar replicar o código-fonte.

Diferenciais Técnicos

  • Endpoint de Configuração Dinâmica: O frontend consome /api/whitelabel/config no carregamento e aplica logos, paletas CSS e títulos em milissegundos.
  • Bancos de Dados Isolados: Instâncias corporativas como Simões Advogados e Itacred operam com instâncias PostgreSQL separadas para segurança e conformidade de dados.
  • Motor Duplo Funil: Separação entre qualificação de leads (SDR) e negociação final (Closer), com algoritmo Round-Robin de distribuição balanceada.

Infraestrutura VPS Linux & Google Cloud Vault

Ambiente: Ubuntu Linux VPS, PM2, Google Drive API v3

Arquitetura de Nuvem

Ambiente de produção construído para sustentar tráfego contínuo com alta resiliência e custo otimizado:

  • Nginx Reverse Proxy: Gerencia terminação TLS com certificados automáticos Let's Encrypt e roteamento para as portas internas dos serviços.
  • PM2 Cluster Manager: Garante uptime de 99.9%, reinicialização automática caso algum processo sofra exceção e monitoramento contínuo de memória.
  • Google Drive API v3: Utilização do fluxo OAuth2 com refresh token para gravação em cofre em nuvem seguro de documentos e comprovantes dos clientes.
